# Week 3 - Day 3 - Authentication Backend Project

## Project Overview

This project is a backend authentication system built using Node.js, Express.js, and MongoDB.

The project includes middleware handling, authentication modules, API routes, and database models.

---

# Features

- User Authentication
- Middleware Implementation
- REST APIs
- MongoDB Integration
- Environment Variable Configuration

---

# Project Structure

| Folder/File | Description |
|-------------|-------------|
| APIs/ | API route files |
| auth/ | Authentication logic |
| middlewares/ | Custom middleware functions |
| models/ | MongoDB models |
| server.js | Main backend server |
| package.json | Dependencies and scripts |
| req.http | API testing requests |
| .env | Environment variables |

---

# Technologies Used

- Node.js
- Express.js
- MongoDB
- JavaScript
