# Backend Development Process

## 1. Initialize Node.js Project

Run the following command:

```bash
npm init -y
```

### Description
This command creates a `package.json` file automatically.

The `package.json` file contains:
- project name
- version
- scripts
- dependencies
- project configuration

---

## 2. Configure package.json

After generating `package.json`, update:

```json
"type": "module",
"main": "server.js"
```

### Description

#### `"type": "module"`
Enables ES6 module syntax in Node.js.

Allows usage of:

```javascript
import express from "express";
```

instead of:

```javascript
const express = require("express");
```

---

#### `"main": "server.js"`

Defines the main entry point of the backend application.

Node.js starts execution from:

```txt
server.js
```

---

## 3. Install Express.js

Run:

```bash
npm install express
```

### Description

Installs the Express.js framework.

Express.js is used for:
- creating HTTP server
- building REST APIs
- handling routes
- middleware support

---

## 4. Import Express Module

Inside `server.js`:

```javascript
import express from "express";
```

### Description

Imports the Express framework into the backend application.

---

## 5. Create Express Application

```javascript
const app = express();
```

### Description

Creates an Express application instance.

The `app` object is used to:
- create routes
- use middleware
- start server
- handle requests

---

## 6. Configure Middleware

```javascript
app.use(express.json());
```

### Description

Built-in Express middleware used to parse incoming JSON request data.

Example:

```json
{
  "name": "Ravi",
  "age": 21
}
```

Without this middleware, Express cannot properly read JSON request bodies.

---

## 7. Create API Routes

Example:

```javascript
app.get("/users", (req, res) => {
  res.json({
    message: "Users API working"
  });
});
```

### Description

Creates a GET API route.

#### Components:
- `app.get()` → handles HTTP GET request
- `"/users"` → API endpoint
- `req` → request object from client
- `res` → response object sent back to client

---

# Common HTTP Methods

| Method | Purpose |
|--------|---------|
| GET | Read data |
| POST | Create data |
| PUT | Update data |
| DELETE | Delete data |

These methods are called CRUD operations.

---

## 8. Start Backend Server

```javascript
app.listen(3000, () => {
  console.log("Server running on port 3000");
});
```

### Description

Starts backend server on port `3000`.

Access server using:

```txt
http://localhost:3000
```
